# MAScope

MAScope 是一个多智能体安全防护系统，旨在对多个智能体之间的协作与交互访问控制，以保证系统安全运行。

## 项目介绍

MAScope： 基于动态标签的流动的访问控制......

## 目录结构

以下是项目的目录结构说明：

```text
MAScope/
├── agents/             # 智能体定义与实现
```

## 快速开始

1. **安装依赖**
   ```bash
   pip install -r requirements.txt
   ```

2. **运行项目**
   ```bash
   python main.py
   ```
